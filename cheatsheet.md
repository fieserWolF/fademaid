# FadeMaid Cheatsheet

## keyboard shortcuts

key | function
---|---
Ctrl+q | quit
Ctrl+b | open background image
Ctrl+o | open fade-data
Ctrl+s | save fade-data
Ctrl+Shift+s | save fade-data as
F1 | show help text
F2 | show about text
Cursor Up | increase value +1
Cursor Down | decrease value +1
Cursor Right | increase value +16
Cursor Left | decrease value +16
i | preview fade in
o | preview fade out
Ctrl+a | toggle auto-mode
k | toggle keymode
s | toggle selectmode
Ctrl+c | copy selected block at mouse position
Ctrl+v | paste selected block at mouse position
Ctrl+x | cut selected block at mouse position
Enter | store value in keymode


## mouse control

mouse action | function
---|---
left mouse button | set value
right mouse button | delete value
